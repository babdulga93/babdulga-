# Command-Line Inventory Manager

A Python-based command-line application designed to track and manage apparel and accessory stock. This tool allows users to add new inventory, view current stock levels, and update quantities directly from the terminal.

## Features
* **Add Items:** Easily add new products to the inventory list.
* **View Stock:** Display all current items and their available quantities.
* **Update Quantities:** Modify stock levels as items are sold or restocked. *(In development)*

## Technologies Used
* Python 3

## How to Run
1. Clone this repository to your local machine.
2. Open your terminal and navigate to the project folder.
3. Run the following command:
   ```bash
   python3 inventory.py
